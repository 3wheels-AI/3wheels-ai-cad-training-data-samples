# CAD Annotation Guidelines

## Objective

Create consistent, machine-readable annotations for CAD and engineering data.

## Core Annotation Categories

### 1. Object / Component

Identify the primary object or component represented by the drawing/model.

Examples:

- bracket
- shaft
- gear
- housing
- fastener
- assembly

### 2. Geometry

Identify relevant geometric entities:

- line
- arc
- circle
- polyline
- curve
- surface
- solid

### 3. Engineering Information

Where applicable, annotate:

- dimensions
- tolerances
- symbols
- labels
- part numbers
- notes
- title blocks

## Quality Rules

- Use consistent labels.
- Preserve units.
- Do not invent missing dimensions.
- Mark ambiguous content for review.
- Validate annotations against the source.
- Record annotation status in metadata.

## Review

Recommended workflow:

`Annotate → Automated Validation → Human Review → Final QC`
