# CAD Training Data Samples

**3Wheels AI — Curated CAD & Engineering Data for AI Development**

This repository provides representative sample data, metadata, schemas, and documentation for **Computer-Aided Design (CAD), engineering drawings, 2D/3D geometry, and industrial design AI applications**.

The repository demonstrates how CAD training datasets can be structured, annotated, validated, and prepared for machine learning and multimodal AI workflows.

> **Note:** This repository is a public sample and demonstration package. It does not represent the full scale of any commercial dataset. Large-scale and customized datasets may be available through commercial data licensing and project-based engagements.
