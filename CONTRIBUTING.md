# Contributing

Thank you for your interest in contributing to the CAD Training Data Samples project.

## Guidelines

- Do not submit proprietary or confidential CAD data.
- Confirm that you have the necessary rights to contribute files.
- Keep metadata accurate and complete.
- Follow the repository naming conventions.
- Add documentation when introducing a new data category.

## Pull Requests

Please explain:

1. What was added or changed.
2. The data category.
3. The source/licensing status.
4. Any metadata or annotation changes.

All contributions are subject to review.
